# ContractKit

Freelance Contracts & Invoices That Get You Paid. Free contract generator with late-fee and kill-fee clauses. PRO unlocks premium templates.

**Live demo:** [https://contractkit-chachi.vercel.app](https://contractkit-chachi.vercel.app)

## Stack

- HTML5, CSS3, JavaScript (vanilla)
- 100% frontend — no build step, no backend
- Deployed on Vercel

## Run locally

```bash
# Serve the src/ directory with any static server
npx serve src/
# or
python3 -m http.server -d src/ 8000
```

Then open http://localhost:8000 (or :3000 for npx serve).
